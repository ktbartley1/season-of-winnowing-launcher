# At Odds Studios Playtest Launcher

Download the latest Windows installer from Releases. Run Setup.exe, sign in with the itch.io account that claimed your invitation, and install the game.

For your in-game username, open At Odds account, create or sign in to your account, verify your email, and save a username. Update the game before launching. All multiplayer participants must use the same updated game version.

The launcher is public. Game downloads remain limited to invited itch.io accounts. No game source or game build is hosted here.

For bugs, attach the launcher's exported diagnostics. Please do not post passwords, invitation keys, sign-in databases, or API tokens. Review game reports before posting them publicly.
