# At Odds Studios Playtest Launcher

Download the latest Windows installer from Releases and run Setup.exe, or choose Update launcher in an existing installation.

## Getting started

1. Create or sign in to your At Odds account, verify your email, and choose your username.
2. Sign in with the itch.io account that claimed your playtest invitation.
3. Install or update the game. Play verifies the latest available version before launching.

## Live playtest activity

The private studio dashboard shows player status, game version, student and session activity. Manage activity sharing in the game Settings.

For bugs, attach the launcher's exported diagnostics. Keep passwords, invitation keys and sign-in information private.
