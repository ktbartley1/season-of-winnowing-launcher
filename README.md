# At Odds Studios Playtest Launcher

Download the latest Windows installer from Releases. Run Setup.exe, sign in with itch.io, and install the game.

The launcher is public. Game downloads remain restricted to invited itch.io accounts. No game source or game build is hosted here.

For bugs, attach the launcher's exported diagnostics. Please do not post passwords, invitation keys, sign-in databases, or API tokens. Review game reports before posting them publicly.
